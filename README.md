## Intended concept

A single-file 3D cyberpunk endless flyer: procedurally generated
corridor geometry and neon lighting, no external art assets, rendered
with Three.js from a CDN so the whole thing stays one HTML file.

## Why the README says this instead of pitching the game

A public repository whose README describes a game in the present tense,
while shipping zero lines of that game, misrepresents the work. The
rest of this account's repositories are held to the rule that the README
describes only what the committed code actually does. This one is now
held to the same rule.
